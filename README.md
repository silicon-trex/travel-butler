# 全能旅行管家 — 多Agent协作旅行规划系统
一款基于多Agent协同的智能旅行规划工具，实现行程生成、应急重规划与价格监控全流程自动化。
我构建了一个名为“全能旅行管家”的多Agent协作系统，用以破解自由行规划中耗时极长且无法应对突发状况的核心痛点。传统规划需要数小时在多平台间反复比价、匹配时间，且航班延误、景点临时关闭等变故会瞬间摧毁整趟行程，重新规划的崩溃感极强。

为彻底解决此问题，我设计了四个专职Agent协同工作的架构，其核心逻辑流包含了典型的动态长链推理过程：

1.偏好解析Agent：负责将用户“带父母、节奏舒缓、偏好人文”等模糊描述，转化为具体的行程刚性约束和柔性偏好权重。

2.行程拓扑生成Agent：依据多目标优化算法，在空间距离、开放时间、体力消耗、餐食口味等十余项约束下，生成多日行程的有向无环图网络。

3.实时保障与议价Agent：在支付环节，并行监控并锁定目标时间段内机票、酒店的最优价格，并能模拟谈判策略，生成对话脚本辅助用户争取免费升房或延迟退房权益。

4.应急重规划Agent（核心长链推理引擎）：这是系统技术深度的集中体现。当发生“航班延误”这类突发事件时，此Agent会被瞬间激活，执行一条持续推演的因果长链。它不会机械地独立改签，而是先在生成的行程拓扑图中进行广度优先搜索，标记所有受影响节点——机票落地时间推迟，意味着当晚酒店的最晚入住时间可能冲突，次日第一班城际火车的取票时间告急，以及已预约的米其林餐厅座位有可能被取消并扣除定金。推理链随后进入闭环优化阶段，尝试解决这一系列连锁冲突，例如自动计算能否将火车票改签至下一车次而不影响后续博物馆导览；同时驱动议价Agent生成与酒店沟通保留房间、与餐厅沟通豁免扣款的话术。整个过程在数秒内完成，最终呈现给用户一套损失最小的备选调整方案，而非将崩溃的烂摊子直接抛给焦虑的用户。

目前，该系统已完成原型闭环测试。在模拟的150组涵盖“极端天气”、“突发闭馆”、“证件丢失”等复杂中断场景中，它能够将重新规划一份可执行行程的平均耗时从人工的40分钟降至10秒以内，方案可行率达92%。其所消耗的大量Token精准地投入在异常分支的万亿级状态空间推演上，确保智能体能像人类旅行专家一样，一眼看透全局连锁反应并给出冷静的对策。
